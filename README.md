# Rubik's Cube 3D Solver

一个单文件 HTML 3D 魔方演示项目。页面中可以直接操作 3x3 魔方，支持鼠标拖动转层、随机打乱，以及按求解步骤播放复原动画。

## 功能

- 3D 魔方渲染，支持鼠标拖动视角
- 拖动魔方面执行真实转层操作
- 随机打乱魔方
- 一键复原，并逐步播放每一步动画
- 复原步骤列表、高亮当前步骤
- 动画速度调节
- 启动时校验转动定义，避免动画方向与求解器状态不一致

## 在线/本地运行

项目目前是纯静态单页应用，不需要构建。

直接打开：

```text
index.html
```

或者在项目目录启动一个本地静态服务：

```bash
python -m http.server 8765
```

然后访问：

```text
http://127.0.0.1:8765/index.html
```

## 技术栈

- [Three.js](https://threejs.org/)：3D 场景、魔方渲染、鼠标拾取和动画
- [cubejs](https://www.npmjs.com/package/cubejs)：3x3 魔方状态建模与 Kociemba 两阶段求解
- 原生 HTML/CSS/JavaScript：无构建工具、无本地依赖

## 使用说明

- 拖动魔方外露面：旋转对应层
- 拖动空白区域：旋转视角
- 鼠标滚轮：缩放视角
- 打乱：生成随机打乱并播放
- 复原：计算实用短解并按步骤播放动画
- 重置：恢复完成状态

## 注意

- 依赖通过 CDN 加载，首次打开需要联网。
- “复原”使用 Kociemba 两阶段算法，通常步数很短，但不保证数学意义上的绝对最少步数。
- 如果 CDN 加载失败，页面会显示错误提示。
